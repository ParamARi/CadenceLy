This is a [Next.js](https://nextjs.org) app in the CadenceLy monorepo. **Use [pnpm](https://pnpm.io/)** (not npm).

## Getting started

From the **repository root**:

```bash
pnpm install
pnpm dev
```

This runs the workspace dev script (e.g. Turbo → `cadencely`).

From **`cadencely/`** only:

```bash
pnpm install
pnpm dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Other commands (in `cadencely/`)

```bash
pnpm build
pnpm lint
pnpm test
```
