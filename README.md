# CadenceLy

An app that filters through your music library based on a selected BPM range to help build personalized playlists. Useful for cadence runners and dancers.

## Development

This repo uses **[pnpm](https://pnpm.io/)** workspaces (`packageManager` is set in `package.json`). Do not use npm for installs.

```bash
pnpm install
pnpm dev
```
