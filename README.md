# CadenceLy
An app that filters through your music library based on a selected bpm range to help build personalized playlists.  Usefull for cadence runners and dancers.

## Start-up

To run this app on your local env, use 'pnpm install' and 'pnpm run dev'

## ngrok

Install ngrok and run 'ngrok http 3000' to tunnel the dev server through an https protocol
